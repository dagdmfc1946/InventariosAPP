# Arquitectura de InventariosAPP v2.3.1

Documento de cierre: 12/10/2026. Describe el sistema implementado y aprobado como
estable, no una propuesta de funcionalidades nuevas.

Abre **[inventariosapp.html](inventariosapp.html)** con doble clic en el Explorador.
Es un HTML autónomo: no requiere Django, Python ni un servidor para consultar el
diagrama. GitHub muestra el código HTML; descarga o clona el archivo para visualizarlo.
Puedes explorar nodos, consultar referencias, cambiar tema y exportar desde el visor.
